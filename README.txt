Gavik portfolio - static site (React loaded from a CDN, no build step).

Deploy on Vercel:
  Option A (terminal):  cd into this folder, then run:  npx vercel --prod
  Option B (GitHub):    push this folder to a repo, import it at vercel.com/new,
                        set Framework Preset to "Other", leave Build Command empty, Deploy.

Edit contact links: open index.html and change the CONFIG line near the top of the script.
